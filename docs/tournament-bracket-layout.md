# トーナメント表レイアウト規則

## 目的と採用方針

本書は、Issue #52のローカル比較で確定した完全順位決定トーナメントの表示規則、
Issue #53で本番画面へ統合した適用条件、Issue #57で追加した表示切替を記録する。

本番画面の既定レイアウトには**水平版**を採用する。垂直版は見慣れた形で視覚品質も高いが、
16チームでは横幅が大きく、画面幅へ縮小するとチーム名と試合情報の可読性が下がる。
水平版はチーム枠を縦に並べてページの縦スクロールへ合わせられるため、画面表示の実用性を
優先して既定とする。

利用者は本番画面で水平版と垂直版を切り替えられる。選択は端末の表示設定として保持し、
大会JSON、トーナメント表、日程、結果、順位には含めない。

## 対象

- 水平版・垂直版を切り替えられるのは、各上位・下位プールの参加数が8または16で、
  `logical_layout.symmetry`が`mirrored`である場合だけとする。選択は上下で共有し、適用可否は
  プールごとに判定する。
- それ以外の参加数、論理配置のない旧JSON、`null`、`permuted`は、理由を日本語で表示して
  標準版へフォールバックする。全プールが非対応の場合は切替を無効化するが、端末の選択は保持する。
- 不正な`logical_layout`は標準版へ黙って切り替えず、図の表示エラーと詳細一覧を表示する。
- 7・9チームのシード／予備戦を含む表は比較fixtureとして保持するが、新レイアウトの品質保証
  対象には含めない。本番統合では、未対応形状を新規則へ無理に当てはめず、既存表示へ
  フォールバックするか、対応規則を別途定義する。
- 水平版・垂直版・標準版はレイアウトと描画処理を一対にした共通presentation registryから
  参照し、本番画面と比較ページで座標規則を共有する。

## 共通表示規則

- チーム名はボックス内に中央揃えで表示する。
- 前の試合の勝者が進む線は実線、敗者が進む線は破線とする。
- 初戦から勝者側と敗者側の両方を描き、勝者側と敗者側を対称な論理木として配置する。
- 順位確定戦の終端は順位順に並べる。高順位側と低順位側の向きは、勝者側と敗者側で
  鏡像になるようにする。
- 日程生成済みの場合は、全試合に試合番号と開始時刻を表示する。
- 決勝、3位決定戦、準決勝は、試合種別と試合番号・開始時刻を2行に分けて中央揃えにする。
- ローカルfixtureの番号・時刻は比較用ダミー値である。本番では日程データを表示し、
  日程未生成時は内部IDやダミー時刻を図へ表示しない。
- 各プール内の1・2位を決める試合を「決勝」、3・4位を決める試合を「3位決定戦」、
  両試合の共通参照元を「準決勝」とする。下位でも全体順位名へ置き換えない。
- 得点、PK、勝者、確定順位は図中の文字を増やさず、試合ごとのアクセシブル説明と
  後続の詳細一覧・最終順位一覧へ残す。
- 文字は線や終端に重ねない。必要な場合は対応する試合線に沿って位置をずらし、
  チーム枠、他の文字、他試合の線との間に余白を確保する。

## 垂直版

- チーム枠を横一列に並べる。
- 勝者側を上、敗者側を下へ展開する。
- 勝者側では決定順位が高い終端ほど上に置き、敗者側では低い終端ほど下に置く。
- 8・16チームで線、枠、試合情報が重ならない縦間隔を確保する。

## 水平版（本番既定）

- 垂直版を時計回りに90度写した対応関係を基本とし、文字自体は回転しない。
- チーム枠を縦一列に並べ、勝者側を右、敗者側を左へ展開する。
- 初戦のチーム枠端から試合線までの実効余白は80pxとする。
- 試合番号と開始時刻は、チーム枠と対応する試合線の間を基本位置とする。
- 順位決定線が試合情報を横切る場合は、対応する試合線の上下または反対側へ
  決定的に移動し、線、枠、他の文字との衝突を避ける。
- 左右端の順位確定戦にも試合情報を配置できる外側余白を確保する。
- 画面ではページ全体を横へはみ出させず、ブラケット領域だけを横スクロール可能にする。
- 画面表示と2日目印刷の既定とし、ブラケット専用印刷では上位・下位を別々のA4縦ページにする。
- 垂直版を選択した場合は、2日目印刷とブラケット専用印刷の双方でA4横ページを使う。

## 比較結果と保留事項

- 垂直版は馴染みやすさと見た目のまとまりでわずかに優れる。
- 水平版は16チーム時の必要横幅を抑え、縦長の本番UIと自然に統合できるため採用した。
- 8・16チームの最終サンプルでは、文字と線、文字と枠、文字同士の意図しない重なりが
  ないことをブラウザ上のSVG境界で確認した。
- 2のべき乗でない参加数の新レイアウトは対象外とし、標準フォールバックは従来のA4横印刷を維持する。

## 本番統合時の注意

- 座標規則を探索用と本番用へ複製せず、同じレイアウト戦略とレンダラーを再利用する。
- 保証条件を満たす表は端末設定に従って水平版または垂直版とし、ブラケット領域だけで必要な
  スクロールを提供する。
- 保存JSON、トーナメント生成、試合結果、順位判定は表示選択によって変更しない。
- 上位・下位トーナメント、仮表・確定表、実日程、印刷で同じ線種と順位順を維持する。
- 非対応形状のフォールバックは明示的に判定し、表示崩れを許容して処理を継続しない。
