# リーグ結果Excelレイアウト

## 位置づけ

この文書はIssue #127で行うレイアウト調整の判断記録である。現時点の内容は、固定fixtureから生成した初回レビュー案であり、人間によるExcel表示・印刷確認を経て確定する。

リーグ結果Excelのデータ検証、出力可否、1ブロック1sheetという構造はIssue #126の実装を引き継ぐ。

## 初回レビュー案

- チームの行と対戦相手の列は、リーグ計画に保存されたブロック登録順を維持する。
- 対戦セルは行側チームの視点で `○ 1-0`、`△ 1-1`、`● 0-1` と表示する。
- 自己対戦は灰色の `—`、未実施は空欄として、色がなくても区別できる凡例を表示する。
- 主表の右側には、勝、分、敗、勝点、得点、失点、得失点差、順位を常時表示する。試合数は順位決定に使わず、勝・分・敗から復元できるため表示しない。
- 勝点と順位を太字にし、対戦表、集計、順位の境界を太罫線で区切る。
- 直接対戦値と順位決定根拠は、主表の横幅を増やさないよう下段の「順位決定記録」へ分離する。
- 抽選記録は抽選番号、候補、確定順をチーム名で表示し、内部digestは表示しない。
- 大会名、ブロック名、保存日時はsheet上部の3行にまとめ、値セルを横方向に結合する。
- ヘッダー情報と主表の間に空行を1行設ける。
- 対戦マトリクスの列見出しと行見出しは同じ淡色に揃え、右側の集計表見出しだけを濃色にする。
- 配色はグレースケールで統一し、構造差は明度、太字、罫線の太さで示す。
- 画面上の行・列固定は行わない。A・B列間に表示されていた固定境界も除去する。
- 印刷はA4横、横1ページ、縦は自動ページ数とし、2ページ目以降で6行目の見出しとA列のチーム名を反復する。
- 2、4、5、8、16チーム、直接対戦、3チーム以上のミニリーグ、残存同点抽選、全引き分け抽選、複数ブロックと長い日本語名の固定fixtureを同じ変更ごとに再生成する。

## 初回レビュー時の確認事項

- 4チーム以下で表が間延びせず、対戦表と集計の対応を追いやすいか。
- 8チームでA4横1ページに無理なく収まるか。
- 16チームで文字が判読でき、縦2ページになった場合も反復見出しから列を追えるか。
- 長い日本語の大会名・チーム名が欠落せず、折返しによって隣接セルを隠さないか。
- マトリクスの淡色見出しと集計表の濃色見出しによって、両者の構造差を自然に読み取れるか。
- 直接対戦と抽選の監査情報が、主表を圧迫せず人間に理解できるか。

ブラウザから生成するPDFは紙面比較用の近似プレビューである。最終判断では、生成したXLSXをExcelまたはLibreOfficeで開き、表示、改ページ、印刷プレビューも確認する。
